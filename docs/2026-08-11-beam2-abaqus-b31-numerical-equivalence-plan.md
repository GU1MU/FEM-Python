# Beam2 按 Abaqus B31 数值行为改造计划

## 状态与核心决定

- 日期：2026-08-11
- 状态：完成（Phase 0–6，2026-08-11）
- 验证模型：`data/portal_frame_b31_wind_snow.inp`
- Abaqus 基准：`data/frame_b31.odb`
- FEM-Python 基准：`data/frame_b31_U.csv`、`data/frame_b31_S.csv`

本计划的核心目标是：在当前项目支持的线性静力范围内，把 `Beam2` 的数值行为整体改造成
Abaqus B31 的一阶 Timoshenko 梁行为，使门式刚架算例的位移、转角和应力误差显著降低，
并由可重复的 Abaqus 对照指标验收。

## 实施记录

- Phase 0–5 已分别冻结 Oracle、替换刚度与分布载荷、收敛方向语义，并完成 B31
  积分点截面力、点应力和不变量恢复；Phase 6 已退役旧端点应力公共恢复及 S11 专用兼容
  命名，收敛 import notice 和结果 provenance。
- 新 Beam2 求解与归档明确记录
  `beam_formulation=abaqus-b31-linear-timoshenko-v1`、
  `beam_result_position=INTEGRATION_POINT` 和 `beam_recovery_contract=4`；旧归档缺少这些
  标识时保持未标记状态，不补写当前公式身份。
- 最终同口径报告位于 `artifacts/validation/frame_b31/phase6/`。32 项数值门槛全部通过：
  117 个节点、276 个单元和 276 个纵向积分点唯一匹配；平移和转角向量相对 L2 分别为
  1.19436×10⁻⁷ 和 1.46143×10⁻⁷；四个截面点共 1,104 条应力记录。

  integration-point/section-point 应力记录，最终 S11、S12、Mises 和 MaxPrincipal 的显著值
  相对 L2 最大值分别为 1.43880×10⁻⁷、1.16182×10⁻⁷、2.43860×10⁻⁶ 和
  1.76371×10⁻⁶。
- 依任务要求，收口验证运行聚焦测试而非全量测试：B31 core/application/io/post/
  characterization/architecture 相关 989 项通过，显式启用 integration 的验收文件 16 项
  通过，相关 GUI 工作流 12 项通过。

本次改造采用以下决定：

1. `Beam2` 类型名、每节点六自由度和公共求解入口继续使用，数值契约直接切换为 Abaqus
   B31 行为。
2. 不保留现有“精确静力 Timoshenko”生产分支，不增加兼容模式、理论切换开关或双内核。
3. 现有三次横向位移插值、与之配套的一致线荷载和旧解析预期，在新实现覆盖对应能力后删除。
4. 旧算法可以通过阶段提交回退，不以运行时分支继续存在。
5. 刚度、位移插值、分布载荷、截面力和应力恢复必须作为同一数值公式整体替换。单独删除
   均布载荷中的梁端力矩项不构成可接受实现。

本计划取代下列旧计划中与本目标冲突的边界：

- `2026-08-10-beam2-linear-static-timoshenko-plan.md` 中“不包含 Abaqus 单元长度相关细长补偿
  和完整 B31 数值等价”的边界；
- `2026-08-09-beam2-section-point-stress-plan.md` 中“不把梁端截面结果改成 Abaqus 梁轴向
  积分点结果”的边界。

## 当前证据与问题基线

以下数据来自现有门式刚架结果的审计。Phase 0 必须用统一脚本重新生成并冻结正式基线；
本节数据用于确定改造方向，不能替代 Phase 0 的验收报告。

### 位移与平衡

| 指标 | 当前结果 | 结论 |
|---|---:|---|
| 平移向量整体相对 L2 误差 | 3.041% | 整体形状高度相关，但刚度存在系统偏差 |
| 显著位移节点平均向量相对误差 | 3.413% | 不是单个异常节点造成 |
| 显著位移节点最大向量相对误差 | 6.671% | 局部误差需要降低 |
| 平移向量最大绝对误差 | 0.2366 mm | 工程量级可见 |
| U1 相对 L2 误差 | 2.733% | 最佳拟合比例约 1.022 |
| U3 相对 L2 误差 | 3.075% | 最佳拟合比例约 1.028 |
| U2 相对 L2 误差 | 53.78% | 参考值较小，但最大绝对差仍约 0.0255 mm |
| 转角向量整体相对 L2 误差 | 21.632% | 梁端转动行为明显不一致 |
| UR2 相对 L2 误差 | 1.160% | 主弯曲转角基本一致 |
| UR1、UR3 相对 L2 误差 | 均超过 400% | 弱响应分量和构件端转角偏差显著 |
| 屋脊端最大转角绝对差 | 约 4.06×10⁻⁴ rad | 会传递到弱轴弯矩和应力 |

程序 CSV 与当前求解器内存结果逐项一致，因此位移误差不来自 CSV 导出。总反力与 Abaqus
在当前数值精度下吻合，说明载荷总合力和约束装配总体正确。反力一致与位移、转角一致是
不同验收维度，前者不能替代后者。

### 应力比较口径

当前程序的矩形截面点 1 坐标为局部正 y、正 z；仓库已有测试把它映射为 Abaqus RECT
截面点 25。比较必须以局部坐标为依据，不能仅依赖 `Top Left Corner`、`Top Right Corner`
文本。若验收选择的是另一物理角点，Phase 0 必须先冻结该点的两套局部坐标和映射。

Abaqus B31 在本算例中每个单元只有一个梁轴向积分点。当前程序 CSV 的 `S` 是由
“梁端刚度作用减等效节点载荷”恢复出的两个端截面值。把该端值与 Abaqus
`ELEMENT_NODAL` 外推值逐行比较，会把结果位置差异计入公式误差。

按正确截面点和本构积分点口径做初步审计后：

- 轴力归一化均方根误差约 2.07%；
- 绕局部 z 轴弯矩归一化均方根误差约 0.45%；
- S11 全模型平均绝对误差约 0.256 MPa。

这些结果说明早期的巨大应力差异含有比较口径问题，也说明当前位移和转角误差仍会进入
积分点内力。最终验收必须同时改正口径并改造梁公式，不能只靠更换比较位置宣布完成。

### 已定位的主要数值差异

当前 `Beam2` 使用精确静力 Timoshenko 三次横向位移插值。均布横向线荷载向量包含大小为
qL²/12 的两端节点力矩。当前 5 m 檩条在 1800 N/m 荷载下，该项为 3750 N·m；审计得到
的檩条弯矩平均差约 3620 N·m。数值量级高度一致，是转角和梁端应力偏差的直接证据。

Abaqus B31 是一阶线性 Timoshenko 梁，并对横向剪切刚度使用与单元长度有关的细长补偿。
因此改造至少要统一替换以下五项：

1. 梁轴向与横向运动学及应变矩阵；
2. 弯曲、剪切、轴向和扭转刚度积分；
3. 横向剪切系数与单元长度细长补偿；
4. 体力、重力和分布线荷载等效节点向量；
5. 积分点截面力、截面点应力和不变量恢复。

## 最终数值契约

### 支持范围

完成本计划后，`Beam2` 的生产数值契约为：

- 两节点、三维、一阶线性 Timoshenko 梁；
- 每节点 `U1/U2/U3/UR1/UR2/UR3` 六自由度；
- 小变形、小应变、各向同性线弹性、线性静力；
- 直梁单元，以及当前 B31 导入器能够表示的单元端方向；
- `RECT`、`CIRC` 和当前映射为厚壁圆管的 `THICK PIPE`；
- 集中载荷、重力、体力和当前已支持的常量 `PX/PY/PZ/P1/P2` 分布载荷；
- Abaqus B31 的一阶插值、纵向积分点语义、横向剪切刚度和细长补偿；
- B31 支持范围内的截面力、`S11/S12/S13` 及由同一点应力张量计算的不变量。

### 本计划不扩大的范围

- 几何非线性、材料非线性、动力学、质量矩阵和阻尼；
- B31H 混合公式；
- 开口截面翘曲、第七自由度、用户自定义横向剪切刚度；
- 薄壁 `PIPE`、任意截面、网格化截面和截面塑性；
- follower load、非均布线荷载和单元内部几何曲率；
- Abaqus 中不属于当前导入与求解能力的关键字或输出变量。

“按 Abaqus B31 行为构造”只在上述支持范围内作数值等价承诺。范围外能力继续返回明确的
capability diagnostic，不通过静默近似扩大承诺。

### 单一实现要求

- `Beam2` 只保留一套刚度、插值、载荷和结果恢复实现。
- 不保留旧公式的环境变量、项目选项、隐藏开关、legacy 类或长期兼容包装。
- 旧项目重新求解时使用新公式；已保存的历史结果保持原值和来源，不伪装成新公式结果。
- 若结果文件需要区分求解公式版本，只增加结果 provenance/schema 版本，不恢复旧求解器。

## 统一测量和验收规则

所有阶段必须使用同一指标定义，避免因筛选、外推或重标定得到表面改善。

### 身份和位置

1. 位移、转角、反力按 Abaqus node label 与 FEM-Python node ID 一一匹配。
2. 截面力和应力按 element label、纵向积分点、截面点局部坐标一一匹配。
3. 当前门式刚架正式验收应覆盖 117 个节点和 276 个 B31 单元；任何缺失、重复覆盖或
   静默丢弃均直接失败。
4. 程序截面点与 Abaqus 截面点用局部 y、z 坐标和 section type 映射。文本描述只作为
   报告信息。
5. Abaqus integration-point `S` 只与程序 integration-point `S` 比较。程序内部梁端 action
   只与 Abaqus 对应的端截面力或独立平衡式比较。

### 误差指标

- 向量相对 L2 误差：全部匹配值的差向量 L2 范数除以 Abaqus 参考向量 L2 范数。
- 分量相对 L2 误差：对同一物理分量使用上述定义。
- 点相对误差只统计参考绝对值大于“该分量最大绝对值的 0.1%”的显著点。
- 弱响应分量必须同时报告全量最大绝对误差，不能因相对分母小而删除。
- 应力全量报告 MAE 和最大绝对误差；相对 L2 只在参考绝对值不小于
  `max(0.1 MPa, 该分量最大绝对值的 0.1%)` 的集合上计算。
- 线性拟合比例和相关系数只用于诊断，不进入通过条件，也不得对程序结果缩放后验收。
- 所有报告同时按柱、拱梁、檩条、墙梁和屋面支撑分组，防止大响应构件掩盖弱响应构件。

### 测试隔离硬约束

`data/` 中的任何文件都不能作为测试用例或测试输入。该约束覆盖单元测试、集成测试、GUI
测试、回归测试、性能 benchmark、smoke test、pytest fixture/parameter、golden、snapshot、
CI 和 coverage 运行，具体要求如下：

1. 测试代码、测试配置和测试辅助函数不得读取、复制、裁剪、转换或派生 `data/` 中的文件。
2. 不得把 `data/` 路径写入测试参数、fixture、golden、snapshot、benchmark 或 CI 命令。
3. 自动化测试所需的梁模型必须由测试代码独立构造，或由独立的最小 INP 文本写入
   pytest `tmp_path`；其节点、单元、载荷和期望值不得从门式刚架产品数据复制。
4. `scripts/compare_frame_b31_odb.py` 是人工执行的工程验证工具，不进入 pytest 收集、测试
   helper 或 CI。门式刚架指标属于独立人工验收报告，不属于自动化测试结果。
5. 独立验收只读访问用户明确指定的 INP、ODB 和 CSV；生成的明细与汇总写入
   `artifacts/validation/frame_b31/` 或命令行指定的非 `data/` 目录，不在 `data/` 中生成
   测试夹具或基准快照。

## Phase 0：冻结 Abaqus oracle 与可信比较基线

### 目标

先消除截面点、结果位置和重复外推造成的比较歧义，建立后续阶段唯一认可的验收工具。

### 设计边界

- 不修改梁刚度、载荷、装配或结果公式。
- 不改变当前 CSV 数值，只修正和扩充比较、提取与报告能力。
- 不把门式刚架或任何 `data/` 文件接入测试、benchmark 或 CI。

### 设计要求

1. 扩展 `scripts/compare_frame_b31_odb.py`，截面点必须显式选择或由局部坐标映射；取消
   默认猜测 `Top Left Corner` 的行为。
2. 增加程序侧基准导出入口，在现有 U/S CSV 之外导出 `UR`、`RF/RM` 和积分点截面结果，
   或输出包含这些字段的统一机器可读快照；不得从仅含平移的 U CSV 推断转角。
3. 从 ODB 提取并比较 `U1/U2/U3`、`UR1/UR2/UR3`、`RF`、可用的 `RM`、`S11/S12/S13`、
   `Mises`、`MaxPrincipal` 以及可用的截面力和截面矩。
4. 在报告中明确区分 `INTEGRATION_POINT`、`ELEMENT_NODAL` 和程序梁端结果，禁止把一个
   Abaqus 积分点的两个外推副本当成两份独立观测。
5. 冻结矩形截面点坐标映射；当前程序点 1 的正 y、正 z 坐标应与 Abaqus RECT 点 25
   进行 oracle 校验。若用户验收角点坐标不同，必须先修正映射再生成正式基线。
6. 输出机器可读明细、汇总、构件分组统计、最差节点/单元列表和运行参数；输出目录必须
   位于 `data/` 之外。
7. 报告记录输入文件散列、step/frame、单位、坐标容差和脚本版本，保证相同输入可重复。

### 验收指标

- 117 个节点全部唯一匹配，276 个单元的目标积分点全部唯一匹配，缺失和额外记录均为 0。
- 位移 CSV 与当前程序重新求解结果的最大绝对差为 0，或只含 CSV 文本舍入误差。
- 程序与 Abaqus 总载荷、总反力的差异在双精度装配容差内，并把实际数值写入报告。
- 正式基线完整复现本计划“当前证据”中的位移误差量级；差异超过 0.1 个百分点时必须解释
  数据版本、截面点或结果位置变化。
- 同一 ODB 和 CSV 连续运行两次，排序、匹配数量和汇总指标完全一致。

### 阶段退出条件

Phase 0 报告经过人工确认后，后续阶段不得临时更换截面点、过滤阈值或结果位置。需要改变
口径时，先更新本计划和基线版本。

## Phase 1：替换为 B31 一阶单元刚度与运动学

### 目标

用单一的一阶线性 Timoshenko 公式替换现有精确静力三次插值和刚度路径。

### 设计边界

- 本阶段只验收无单元分布载荷的单元刚度、集中载荷和节点自由度响应。
- 暂不改变 `S` 字段的位置和不变量实现。
- 保持现有 `Beam2` 类型名、装配入口、全局自由度编号和局部右手坐标约定。

### 设计要求

1. 建立 B31 一阶平移和转动插值、轴向应变、两向曲率、两向剪切应变和扭转应变矩阵。
2. 按 B31 的纵向积分规则计算刚度；剪切项不得复用旧三次插值参数。
3. 横向剪切刚度按截面类型计算，并分别对两个弯曲方向应用 Abaqus 一阶梁的单元长度
   细长补偿。默认 shear correction、slenderness compensation factor 和泊松比依赖由
   官方公式与最小 Abaqus oracle 双重冻结。
4. 常量方向和单元端方向变化路径必须消费同一 B31 strain/interpolation owner。
5. 删除旧 `_beam2_bending_interpolation` 的生产调用；对应旧精确静力断言改成 B31 oracle
   或一阶 Timoshenko 解析断言。
6. 刚度矩阵保持对称，坐标旋转、节点顺序反转和两弯曲方向的符号约定保持协变。

### 验收指标

- 自由单元刚度矩阵具有且仅具有 6 个刚体模态，无额外零能模态；对称性误差不超过
  矩阵最大绝对项的 10⁻¹²。
- 刚体平移和刚体转动的应变能不超过代表性弹性变形能的 10⁻¹²。
- 对 `RECT/CIRC/THICK PIPE`、两个弯曲方向和至少三个细长比建立独立单元 oracle；集中
  节点载荷下每个显著 U/UR 分量相对 Abaqus 误差不超过 0.5%。
- 轴向和 Saint-Venant 扭转用例的位移、转角和反力相对误差不超过 10⁻⁸。
- 等价模型整体旋转或反转 connectivity 后，变换回同一全局坐标的解相对差不超过 10⁻¹⁰。
- 仓库中不存在第二套可被生产代码调用的旧梁刚度或插值分支。

### 阶段退出条件

集中载荷 oracle、刚体模态和坐标协变测试全部通过后，才允许进入分布载荷改造。

## Phase 2：按同一一阶插值重建分布载荷

### 目标

让体力、重力和线荷载的等效节点向量与 Phase 1 的一阶运动学一致，消除旧三次插值带来的
额外梁端节点力矩。

### 设计边界

- 覆盖当前已支持的常量 `PX/PY/PZ/P1/P2`、重力和均匀体力。
- 不增加线性变化荷载、曲线梁 follower load 或新的 Abaqus DLOAD 标签。
- 本阶段先保持结果字段不变，使用位移、转角、反力和内部虚功验收。

### 设计要求

1. 从 Phase 1 的平移插值直接积分等效节点载荷，不手写与刚度无关的闭式常量表。
2. 常量横向线荷载不再产生旧公式的正负 qL²/12 梁端节点力矩；该变化必须来自整套一阶
   插值替换。
3. local 与 global DLOAD 在同一 element frame 中转换，connectivity 反转后保持正确符号。
4. 重力先由材料密度和截面面积得到单位长度力，再走同一分布载荷积分路径。
5. `local_stiffness @ local_displacement - local_load` 可以继续作为梁端平衡 action 的内部
   计算，但不得继续承担 Abaqus 积分点应力恢复。

### 验收指标

- 每个分布载荷最小用例的节点等效力合力、关于任意端点的合矩与连续荷载解析值之差不超过
  参考量的 10⁻¹²。
- 两节点一阶横向均布荷载向量与 Abaqus B31 oracle 一致；旧 qL²/12 项的回归测试被删除。
- 悬臂、简支和刚架最小模型在两局部方向的 U/UR、RF/RM 相对 Abaqus 误差不超过 1.0%。
- 门式刚架平移向量整体相对 L2 误差降至 1.5% 以下；U1、U3 各自低于 1.5%。
- 门式刚架转角向量整体相对 L2 误差降至 10% 以下；屋脊端最大转角绝对误差低于
  1.5×10⁻⁴ rad。
- 5 m 檩条中与旧 qL²/12 同量级的系统性端弯矩偏差消失；各檩条不得保留同符号、同量级
  的约 3.6–3.8 kN·m 偏置。

### 阶段退出条件

最小分布载荷 oracle 和门式刚架位移中间门槛同时通过。只有平衡正确、位移未改善时，
本阶段不能通过。

## Phase 3：收敛 B31 方向、节点法向和装配语义

### 目标

消除默认 n1、共享节点法向和单元端 frame 差异对弱向位移、转角与弯矩的影响。

### 设计边界

- 覆盖当前导入器已识别的 section n1、Abaqus 默认 n1、additional orientation node、
  节点 normal 和 `*NORMAL`。
- 不扩展到曲梁几何、翘曲自由度或几何非线性。
- 门式刚架没有显式 normal 的位置，必须按 Abaqus 默认生成与分组规则处理。

### 设计要求

1. 方向解析保持 element-end identity，同一共享节点允许不同构件方向组。
2. section n1、默认 n1、orientation node、nodal normal 和 generated/averaged normal 的
   优先级及容差由官方语义或独立 Abaqus oracle 冻结。
3. frame 解析结果与 Phase 1 的刚度、Phase 2 的 local load 和后续结果恢复共用，不在
   builder、kernel 和后处理各算一份。
4. 方向生成对 element/set 输入顺序保持确定性；无效、平行或冲突方向继续 fail closed。
5. 当前 builder 中只因尚未等价而存在的 approximate-normal notice，在本阶段通过对应
   oracle 后删除；范围外 notice 继续保留。

### 验收指标

- kink、T junction、closed loop、反向 connectivity 和多方向组最小模型的 element-end
  frame 与 Abaqus oracle 一致，方向余弦最大绝对差不超过 10⁻¹⁰。
- 输入 element、node 和 set 顺序置换后，按 identity 排序的 frame、刚度、载荷和结果完全
  一致。
- 门式刚架平移向量整体相对 L2 误差低于 1.0%；显著节点最大向量相对误差低于 3.0%。
- U2 相对 L2 误差低于 15%，且最大绝对误差低于 0.010 mm。
- 转角向量整体相对 L2 误差低于 5.0%；UR1、UR3 的最大绝对误差均低于
  5×10⁻⁵ rad；屋脊节点转角向量相对 L2 误差低于 15%。

### 阶段退出条件

方向 oracle 和门式刚架弱响应门槛同时通过。若门式刚架已无需新增方向能力，仍须用报告
证明误差来源已转移到结果恢复，不能跳过证据直接关闭本阶段。

## Phase 4：改为 B31 积分点截面力与 S11 恢复

### 目标

让公开的梁 `S` 和截面力遵循 Abaqus B31 纵向积分点语义，停止把梁端 action 当作
Abaqus 积分点应力。

### 设计边界

- 本阶段先完成轴力、双向弯矩和 S11。
- 梁端 action 继续作为平衡检查的内部量，但不再作为公开 `S` 的数值来源。
- S12、S13 和不变量等价放在 Phase 5。

### 设计要求

1. 使用与 Phase 1 相同的积分点、应变矩阵和材料矩阵恢复轴向应变、曲率和截面结果量。
2. B31 一阶梁每个单元发布一个纵向积分点结果；`ELEMENT_NODAL` 仅在明确请求时由统一
   外推器生成，并标注为外推结果。
3. `S11` 按 section point 的真实局部坐标由积分点轴力和双向弯矩恢复。
4. 矩形点映射按局部坐标冻结；程序点 1 与 Abaqus RECT 点 25 的关系由测试直接验证，
   不能依赖显示名称。
5. 结果查询、CSV、归档和 GUI 保留 `INTEGRATION_POINT` 身份。若旧归档只有梁端值，继续
   按旧 provenance 读取，不把它转换成积分点值。
6. 端截面平衡 action 和积分点本构结果使用不同的内部类型或位置身份，禁止再次混用。

### 验收指标

- 纯轴力和双向纯弯曲最小模型的积分点 N/My/Mz、S11 与 Abaqus 相对误差不超过 0.5%。
- 门式刚架正确角点的积分点 S11：显著值相对 L2 误差低于 2.0%，全量 MAE 低于
  0.20 MPa，最大绝对误差低于 1.0 MPa。
- 门式刚架积分点轴力相对 L2 误差低于 1.5%，主弯矩分量相对 L2 误差低于 1.0%。
- 柱、拱梁、檩条、墙梁和屋面支撑五组均有独立统计；任何一组 S11 MAE 不超过
  0.35 MPa。
- 276 个单元各产生且只产生一个目标纵向积分点记录；外推输出不得增加独立样本计数。
- 梁端 action 与外载荷继续满足局部和全局平衡，结果位置改变不能破坏反力。

### 阶段退出条件

必须同时通过积分点身份、解析载荷用例和门式刚架 S11 指标。仅把两个端值平均后命名为
积分点结果不满足设计要求。

## Phase 5：补齐 B31 剪应力与应力不变量

### 目标

让 `Mises` 和 `MaxPrincipal` 由与 Abaqus 相同截面点的完整受支持应力分量计算，结束
当前矩形角点强制剪应力为零所造成的不变量契约差异。

### 设计边界

- 覆盖 `RECT/CIRC/THICK PIPE` 的线弹性 B31 截面点剪应力。
- 不实现任意截面、开口截面翘曲、塑性截面或用户自定义截面网格。
- 若 Abaqus 某截面点不发布某一分量，程序保持相同缺失语义，不用零值伪造。

### 设计要求

1. 用独立的纯横向剪力、纯扭转和组合载荷 oracle 冻结 Abaqus `S12/S13` 的局部轴、正负号
   和截面点分布。
2. 从积分点 `Vy/Vz/T` 和截面几何恢复同一截面点的 `S12/S13`；不得把截面级最大剪应力
   填入每个截面点。
3. `Mises`、`MaxPrincipal` 及其他保留的不变量只使用同一 element、integration point、
   section point 的应力张量。
4. 结果系统增加必要的 `S13` 分量身份；CSV、查询、归档和 GUI 共享同一数据，不各自重算。
5. 删除“矩形角点横向剪切永远不影响点应力”的旧生产假设和对应永久回归预期。

### 验收指标

- 三种截面、两个横向剪切方向和正反扭矩的最小 oracle 中，显著 `S12/S13` 相对误差均
  不超过 2.0%，符号和零值位置完全一致。
- 纯轴力、纯弯曲和无剪力用例的不变量不因本阶段产生回归，误差不超过 10⁻⁸。
- 门式刚架 `Mises` 显著值相对 L2 误差低于 3.0%，全量 MAE 低于 0.25 MPa。
- 门式刚架 `MaxPrincipal` 显著值相对 L2 误差低于 5.0%，全量 MAE 低于 0.25 MPa。
- 所有不变量均可逐记录由导出的同点应力分量复算；最大复算差不超过输出值最大绝对值的
  10⁻¹²。

### 阶段退出条件

S11、剪应力和不变量必须使用同一积分点及截面点身份。只让 S11 通过、继续沿用旧
`Mises/MaxPrincipal` 公式时，本阶段不能通过。

## Phase 6：端到端收口、旧公式退役与回归

### 目标

完成门式刚架最终验收，删除旧数值实现和旧行为测试，收敛导入 notice、结果版本与文档。

### 设计边界

- 不在本阶段新增梁理论或截面类型。
- 只处理前五阶段引入的兼容、归档、GUI 和测试收口。
- 不修改项目 README，除非另有明确任务。

### 设计要求

1. 删除旧三次插值、旧精确静力刚度、旧 qL²/12 载荷项和不再使用的私有辅助函数。
2. 删除或改写把旧精确静力结果冻结为正确答案的测试；无效梁、刚体模态、平衡和 API
   契约等仍有效测试继续保留。
3. B31 import notice 只列出仍未支持的真实边界，不再报告已完成的 shear deformation、
   slenderness compensation、方向或积分点近似。
4. 新求解结果记录 B31-equivalent formulation provenance；旧结果档案可读、不可伪装。
5. 运行单元、装配、求解、导入、后处理、CSV、归档和 GUI 完整回归。
6. 保存 Phase 0 与最终报告的同口径差异表，不能只保存最终百分比。

### 最终验收指标

| 类别 | 必须达到的最终门槛 |
|---|---|
| 节点/单元匹配 | 117 个节点、276 个单元全部唯一匹配，缺失和重复均为 0 |
| 总反力 | 各全局分量相对差不超过 10⁻⁶；近零分量绝对差不超过总载荷的 10⁻¹⁰ |
| 平移向量 | 整体相对 L2 误差 ≤ 1.0% |
| 显著节点平移 | 平均向量相对误差 ≤ 1.5%，最大值 ≤ 3.0% |
| U1、U3 | 各分量相对 L2 误差 ≤ 1.0% |
| U2 | 相对 L2 误差 ≤ 15%，最大绝对误差 ≤ 0.010 mm |
| 转角向量 | 整体相对 L2 误差 ≤ 5.0% |
| 弱转角 | UR1、UR3 最大绝对误差均 ≤ 5×10⁻⁵ rad |
| 屋脊转角 | 向量相对 L2 误差 ≤ 15% |
| 积分点 S11 | 显著值相对 L2 误差 ≤ 2.0%，全量 MAE ≤ 0.20 MPa |
| Mises | 显著值相对 L2 误差 ≤ 3.0%，全量 MAE ≤ 0.25 MPa |
| MaxPrincipal | 显著值相对 L2 误差 ≤ 5.0%，全量 MAE ≤ 0.25 MPa |
| 构件分组 | 五个构件组分别出具统计，无缺组、无静默过滤 |

弱向位移或应力位置未通过。

### 阶段退出条件

完整测试和门式刚架最终报告通过后，才允许把计划状态改为完成。若某个指标未通过，报告
必须定位到构件组、自由度或结果位置，并回到对应阶段修正，不能在 Phase 6 放宽口径。

## 阶段依赖与提交边界

实施顺序固定为：

1. Phase 0 冻结可信 oracle；
2. Phase 1 替换运动学和刚度；
3. Phase 2 替换分布载荷；
4. Phase 3 收敛方向和装配；
5. Phase 4 切换积分点 S11；
6. Phase 5 补齐剪应力和不变量；
7. Phase 6 删除旧公式并完成端到端收口。

每个 Phase 独立提交并保留其验收报告。Phase 1 和 Phase 2 可以在同一开发分支连续进行，
评审与验收仍须分开，避免用载荷变化掩盖刚度变化。Phase 4 之前不得把梁端 action 重命名为
积分点结果；Phase 6 之前不得以兼容为由恢复旧运行分支。

## 关键风险与控制

### 风险 1：比较脚本制造虚假改善

控制：Phase 0 冻结身份、位置、截面点坐标和过滤阈值；最终报告沿用同一配置。拟合缩放
只作诊断。

### 风险 2：只删除均布载荷节点力矩

控制：刚度、运动学和载荷分别在 Phase 1、Phase 2 用 Abaqus oracle 验收。旧 qL²/12
项只能随旧插值整体退役。

### 风险 3：细长梁出现剪切锁定或经验调参

控制：三个以上细长比、两个弯曲方向和三种截面同时对照；补偿参数来源集中，禁止为门式
刚架单独拟合系数。

### 风险 4：端截面值继续冒充积分点应力

控制：结果类型显式携带 position identity；端 action 与 integration-point result 使用不同
内部契约，比较脚本拒绝跨位置比较。

### 风险 5：相对误差被近零分量放大或被过滤掩盖

控制：弱响应同时设置相对与绝对门槛，完整导出全量误差和最差位置，过滤只影响相对统计。

### 风险 6：旧项目兼容重新引入双内核

控制：兼容只发生在结果读取和 provenance 层。重新求解统一走新 `Beam2`，架构测试禁止
旧公式被生产代码调用。

## 完成定义

本计划只有在以下条件全部满足时完成：

- `Beam2` 生产代码只剩一套 Abaqus B31 一阶线性 Timoshenko 数值实现；
- 刚度、方向、分布载荷、积分点截面力和应力恢复使用同一运动学与 frame 契约；
- 门式刚架按 Phase 0 固定口径达到 Phase 6 全部最终门槛；
- `S11`、`Mises`、`MaxPrincipal` 按正确纵向积分点和截面点比较；
- 旧精确静力公式、旧 qL²/12 载荷项和旧行为断言已从生产路径及测试期望中退役；
- B31 import notice 准确描述剩余能力边界；
- 完整自动化测试通过，且仓库内任何测试、测试辅助代码、benchmark 或 CI 均不读取、复制
  或派生 `data/` 中的文件。

完成“比较脚本修正”、只让平移改善、只让 S11 改善或继续保留旧公式运行分支，均不满足
本计划的完成定义。
