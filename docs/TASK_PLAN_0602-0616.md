## 任务1 Mixed Elements CAE模型 (3D+2D)

### 任务流程

- **模型目标**：确定一个较复杂的混合单元算例，覆盖至少两类实体单元共存的模型
- **Abaqus基准**：使用Abaqus建立模型，导出`inp`文件，并保存`odb`结果
- **输入读取**：确认当前`inp`读取能够正确处理模型中的信息
- **求解验证**：运行项目线性静力求解
- **结果对比**：导出CSV和VTK结果，比较项目结果与Abaqus结果的位移、单元应力和节点应力差异

### 验收结果

- 有一个明确的复杂mixed elements CAE输入文件
- 模型至少包含两类实体单元，且包含多`set`、多材料或复杂边界等特征
- 项目能够读取模型并完成线性静力求解
- 位移、单元应力、节点应力和VTK结果能够正常导出
- 形成一份Abaqus对比报告，说明主要结果差异和待修正问题

### 格式要求

- Paraview和Abaqus中的截图应当白底、无光影、视角一致
- 云图需要给出Colorbar
- 多图需要标注a, b, c, d...
- 表格使用三线表
- 不需要很多文字阐述

## 任务2 修正3D节点应力插值

### 任务流程

- **差异定位**：选取`Hex8`、`Tet4`和`Tet10`的代表性3D算例，对比项目节点应力与Abaqus节点应力结果
- **算法梳理**：梳理当前节点应力来源，区分单元Gauss点应力、节点外推应力、节点平均应力和导出字段
- **插值策略**：确认3D单元节点应力采用的外推矩阵、形函数插值或体积加权平均方式
- **Abaqus对齐**：明确项目结果与Abaqus结果对比时使用的是积分点应力、外推节点应力还是平均节点应力
- **回归测试**：补充3D节点应力插值测试，覆盖单一单元、规则网格和混合单元模型

### 验收结果

- 能解释当前3D节点应力与Abaqus差异的主要来源
- `Hex8`、`Tet4`和`Tet10`节点应力插值逻辑有清晰实现路径
- 修正后的节点应力结果与Abaqus同口径结果误差进入可接受范围
- 节点应力CSV和VTK导出使用一致的节点应力数据来源
- 有对应回归测试防止后续修改破坏3D节点应力结果

## 任务3 引入Newmark时间差分

### 任务流程

- **需求边界**：将现有静力求解升级为Newmark兼容时间差分框架下的准静态特例，控制方程按$Ku_{n+1}=f(t_{n+1})$组织，暂不引入惯性项和阻尼项
- **时间网格**：设计通用`TimeGrid`，保存$t_0,t_1,\dots,t_n$、$\Delta t$、帧编号和时间单位，为静力多帧和后续动力学共用
- **幅值函数**：设计通用`Amplitude`，使节点载荷、面载荷和位移边界能够按$A(t)$缩放
- **状态历史**：设计通用`TimeState`，每帧保存$t_n$、$\Delta t_n$、$u_n$、$\Delta u_n$、反力，并预留$v_n$和$a_n$字段
- **差分输出**：由相邻静力帧计算$\Delta u_n=u_n-u_{n-1}$和$v_n\approx\frac{u_n-u_{n-1}}{\Delta t_n}$，作为后处理或结果字段输出
- **Newmark兼容**：接口设计参考Newmark-$\beta$格式，保留后续由$u_n$、$v_n$、$a_n$推进的扩展空间
- **求解器升级**：将原有静力求解器统一为时间差分求解框架
- **结果导出**：按帧导出CSV和VTK结果，例如`step1_0000.vtk`、`step1_0001.vtk`，用于查看多帧变形和应力变化

### 验收结果

- 有清晰的时间网格、幅值函数和时间帧结果结构
- 至少一个准静态算例能够完成多时间帧计算
- 每帧结果能够保存位移、位移增量、可选差分速度和反力
- 结果能够按帧导出CSV和VTK文件
- 原有静力求解入口能够通过时间差分框架运行，
- 接口保留Newmark-$\beta$动力学扩展所需的$u$、$v$、$a$状态历史
- 新增测试覆盖时间网格、载荷幅值缩放、逐帧静力求解和多帧结果导出

## 任务4 编写数据结构和类对象说明

### 任务流程

- **文档范围**：编写一份面向项目开发的简洁说明，主旨是解释项目中的数据结构、类对象和公开调用方法
- **核心对象**：说明`Node2D`、`Node3D`、`Element2D`、`Element3D`、`Mesh`、`FEMModel`、`AnalysisStep`、`ModelResult`等对象的用途
- **模型数据**：说明`NodeSet`、`ElementSet`、`Surface`、`MaterialDefinition`、`SectionAssignment`、`DisplacementConstraint`、`NodalLoad`和`SurfaceLoad`的字段含义和使用效果
- **外部方法**：梳理外部调用常用方法，如`mesh.node_dofs`、`mesh.global_dof`、`model_element_info`、`steps.displacement`、`steps.nodal_load`、`solvers.static_linear.solve`和结果导出函数
- **调用示例**：每类对象只给最小示例，说明如何创建、传入哪里、执行后产生什么效果
- **接口边界**：只记录稳定的公开接口，内部辅助函数和临时实现不作为主要说明对象
- **语言要求**：用最简洁的语言描述使用方法和效果

### 验收结果

- 有一份独立的数据结构和类对象说明文档
- 文档覆盖主要类对象的用途、关键字段、外部调用方法和调用效果
- 每个公开方法说明包含输入、输出或副作用中的至少一项
- 文档语言简洁
